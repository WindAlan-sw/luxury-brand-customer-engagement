# Quick Start

This repository is meant to be used in less than five minutes.

## 1. Check the results

Open:

```text
notebooks/01_Check_Published_Results.ipynb
```

Run all cells. The notebook loads the public metric files, shows the post-level and brand-month analysis, and recreates key result tables/figures.

## 2. Reproduce the core public analysis

Open:

```text
notebooks/02_Reproduce_Public_Metric_Analysis.ipynb
```

This notebook reproduces entropy weighting, CRITIC comparison, fixed-effect style modelling, and clustering from the de-texted public metrics.

## 3. Apply the framework to your own data

Open:

```text
notebooks/05_Apply_Framework_To_Your_Data.ipynb
```

Replace the example data with your own brand/post/customer engagement metrics.

## Important note

The public repository reproduces the empirical analysis from de-texted public metrics. It does not redistribute raw social-media text or user identifiers.
