# Restricted Data Note

The original research files contain row-level social-media content, including text, cleaned text, handles, display names, URLs, mentions, hashtags, and timestamps. These files are not included in the public repository.

The public metrics in this repository were generated from those files after removing direct text and user-identifying fields. Customer/user-generated records are aggregated before public release.

Restricted files not shared publicly include the original brand CSV files, customer Excel files, row-level text datasets, and any notebook outputs that display raw text or credentials.
