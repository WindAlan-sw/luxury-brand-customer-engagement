# Data

This folder contains public analysis-ready data only.

## `public_metrics/`

These CSV files were derived from the original research datasets after removing raw text, cleaned text, handles, names, URLs, mentions, hashtags, and other direct user/content fields.

The public analysis follows two phases:

1. `01_brand_post_metrics_detexted.csv` provides post-level official brand engagement metrics.
2. Brand-month panels and derived metric files reproduce the aggregate analyses used in the published study.

## `restricted_not_shared/`

This folder is intentionally empty. Original raw social-media datasets are not redistributed.
